## 📌 Overview

**Tech Portfolio** is my personal developer portfolio, designed to showcase my technical skills, projects, professional experience, certifications, and learning journey across Cloud Computing, DevOps, Web Development, and Generative AI.

The website combines a terminal-inspired interface with a deployment-log aesthetic, bringing together a developer-focused visual style and a structured presentation of my work.

It serves as a central place to explore my projects, understand the technologies behind them, and access their source code or detailed project pages.

🔗 **Live Website:** https://gurjyot-gurz.github.io/Tech-Portfolio/

## ✨ Key Features

- **Terminal-Inspired Design:** A developer-themed interface inspired by command-line tools and deployment logs.
- **Project Showcase:** Dedicated cards for projects with descriptions, technology tags, status indicators, and relevant links.
- **Project Case Studies:** Structured project pages that help visitors explore project objectives, implementation details, architecture, and screenshots where available.
- **Skills & Technologies:** An organized overview of technical skills across cloud infrastructure, DevOps, programming, and AI.
- **Professional Experience:** Highlights internships and practical project experience.
- **Certifications Gallery:** A dedicated area for professional certifications and learning achievements.
- **GitHub Integration:** Links to source repositories and project documentation.
- **Automated Updates:** A scheduled GitHub Actions workflow for refreshing GitHub contribution-related data.
- **Responsive Layout:** Designed to provide a usable experience across desktop and mobile screen sizes.
- **Interactive UI:** JavaScript-powered interface elements and visual interactions.

## 🔄 Deployment & Automation

The portfolio is hosted using **GitHub Pages**, allowing the website to be published directly from its GitHub repository.

The workflow is designed around a simple development and publishing process:

```text
Source Code
    ↓
GitHub Repository
    ↓
GitHub Actions Workflows
    ↓
GitHub Pages
    ↓
Live Portfolio
```

A separate scheduled workflow supports the refresh of GitHub contribution-related data.

## 🚀 Run Locally

You can run the portfolio locally to explore the code or make changes.

### 1. Clone the repository

```bash
git clone https://github.com/Gurjyot-gurz/Tech-Portfolio.git
```

### 2. Open the project directory

```bash
cd Tech-Portfolio
```

### 3. Launch the website

Open the main `index.html` file in your browser.

For local development, you can also use the Live Server extension in Visual Studio Code.
