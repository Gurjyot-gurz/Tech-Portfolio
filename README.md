# 📖 About

This repository contains my personal portfolio website built with
**HTML5, CSS3 and Vanilla JavaScript**.

Instead of using a traditional portfolio layout, I designed the website
to resemble a real DevOps workflow.

The complete experience follows five stages:

-   **STAGE 01 · SOURCE**
-   **STAGE 02 · BUILD**
-   **STAGE 03 · DEPLOY**
-   **STAGE 04 · VERIFY**
-   **STAGE 05 · MONITOR**

Every section is inspired by Linux terminals, Kubernetes, CI/CD
pipelines and deployment logs.
